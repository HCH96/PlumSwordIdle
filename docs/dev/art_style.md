# 제자 기준 아트 스타일

새 에셋을 구상하고 생성할 때 이 문서와 [에셋 목록](assets.md), [크기·가져오기 기준](art.md)을 함께 확인한다. 2026-11-17부터 아래 제자 SD를 공통 스타일 참고로 사용한다. 새 에셋을 비교하며 세부 기준은 조정할 수 있다.

## 기준 자료

| 용도 | 자료 |
| --- | --- |
| 일러스트 시안의 캐릭터 디자인·분위기 참고 | [제자 일러스트](../../art/source/disciple/illustration_concept.png) |
| 픽셀 스프라이트의 비율·형태·색감 참고 | [제자 기본 스프라이트](../../art/source/disciple/base_south-east.png) |
| 동작과 검격의 표현 참고 | [17프레임 공격 시트](../../art/source/disciple/attack_south-east_sheet.png) |
| 원본과 PixelLab ID, 프레임 및 미리보기 | [제자 에셋 색인](../../art/source/disciple/index.md) |

일러스트는 디자인을 설명하는 자료이고, 게임 화면에서 픽셀의 실제 밀도와 형태를 비교하는 기준은 스프라이트다. 기본 스프라이트는 64×64px, 남동쪽 방향, PixelLab의 low top-down 시점이다. 공격 원본은 76×76px × 17프레임이다. 두 숫자는 원본 크기이며 게임 적용 크기와 피벗을 이미 결정했다는 뜻은 아니다.

## 공통 표현

- **시점과 방향**: 제자처럼 살짝 위에서 내려다보는 3/4 시점으로 얼굴과 의상 앞면이 보인다. 전투에서 제자는 화면 오른쪽, 적은 왼쪽을 향하도록 각각 자연스러운 방향을 만든다. 단순 좌우 반전으로 의상·무기 배치가 어색해지지 않는지 확인한다.
- **비율과 실루엣**: 큰 머리와 작은 몸의 SD 캐릭터. 일반 사람형 적은 제자와 나란히 보며 몸 크기와 머리 비율을 맞춘다. 보스는 더 크게 보이되 같은 표현 밀도를 유지한다. 검과 팔·다리의 동작이 작은 화면에서도 구분되어야 한다.
- **선과 명암**: 어두운 외곽선과 제한된 색조로 형태를 구분하고, 명암은 제자처럼 선명한 덩어리로 표현한다. 제자 원본의 실제 질감을 참고하며, 일괄적인 1px 선이나 정확한 색 수를 이미 충족한다고 가정하지 않는다.
- **색**: 제자는 검정·짙은 회흑색 의상과 자주·짙은 붉은색 끈, 밝은 검날이 중심이다. 매화 분홍은 시선을 끄는 포인트로 사용한다. 적은 구분되는 대표색을 가질 수 있지만 제자 옆에서 지나치게 이질적으로 보이지 않게 한다. 고정 공통 팔레트와 색상 수는 아직 확정하지 않았다.
- **배경**: 캐릭터와 같은 시점 및 픽셀 밀도를 기준으로 한다. 캐릭터가 읽히도록 배경의 대비와 채도를 조절하고, 먼 산·중간 풍경·땅의 레이어를 비교한다. 실제 배경을 만든 뒤 톤을 확정한다.
- **이펙트와 UI**: 검격은 저장된 공격의 흰색·분홍색을 참고하되 게임에서 동작과 겹쳤을 때 알아볼 수 있게 한다. UI는 제자와 배경 옆에서 색과 선의 무게를 비교한다.

## 제작과 확인

1. [에셋 목록](assets.md)에서 대상을 고르고, 사람이 가져온 참고 이미지에서 원하는 특징을 확인한다. 기존 작품의 구체적인 캐릭터나 디자인을 복제하지 않고 게임에 맞게 해석한다.
2. 제자 일러스트의 분위기를 참고해 새 일러스트 시안을 만들고 사람이 고른다.
3. 선택한 시안과 제자 기본 스프라이트를 참고해 PixelLab MCP로 기본 스프라이트를 만든다. 도구가 참고 이미지를 받는 경우 해당 자료를 넣고, 지원하지 않으면 기준을 프롬프트에 명시한다.
4. 기본 스프라이트를 제자 옆에 놓고 비율, 방향·시점, 픽셀 밀도, 선, 색감, 가독성을 비교한다. 사람이 확정하기 전에는 그 기본 스프라이트로 애니메이션을 만들지 않는다.
5. 확정된 기본 스프라이트로 필요한 애니메이션을 생성하고 사람이 확인한다. 프레임 순서와 움직임, 제자리 위치, 잘림, 공격 시 이펙트를 살핀다. 재생 속도는 게임 동작에 맞춰 추후 정할 수 있다.
6. 선택한 자료의 시안·기본 그림·애니메이션 원본과 프레임, 미리보기, 생성 문구와 설정·참고 자료, PixelLab ID를 `art/source/<에셋>/`에 보관하고 해당 폴더에 색인을 둔다. 게임용 파일이 준비되면 `Assets/Resources/`에 별도 저장하고 [에셋 목록](assets.md)에 연결한다. 원본을 덮어쓰지 않는다.

## 아직 결정할 것

- 적의 캔버스 크기와 화면상 크기. 제자는 2026-11-17에 원본 칸(76×76·76×80, 몸 키 약 53px, PPU 32)으로 적용했다 ([에셋 목록](assets.md)). 적은 제자 옆에서 몸 크기를 맞춰 정한다. 기존 목록의 적 48×48은 계획값이다.
- 고정 팔레트와 정확한 색 수, 배경·UI 세부 표현. 첫 몬스터와 배경을 제자와 비교하며 정한다.
- 제자 공격은 임시로 `17 ÷ 공격 간격` fps에 7번 프레임을 피해 시점에 맞췄다. 달려와 멈춘 첫 공격도 앞 동작(0~6번) 시간만큼 피해를 늦춰 같은 프레임에 맞춘다 ([전투 사양](../spec/combat.md) "동작" 2-1, "제자 애니메이션"). 최종 속도는 아직 정하지 않았다.
