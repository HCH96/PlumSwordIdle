# 픽셀아트 에셋 기준

모든 스프라이트와 화면 코드가 따르는 크기 기준이다. 에셋을 새로 만들거나, 화면 코드에서 카메라·UI 크기·대체 표시 크기를 정할 때 이 문서를 따른다.

## 기본 숫자

| 항목 | 값 | 비고 |
| --- | --- | --- |
| 화면 방향 | 가로 | |
| 기준 해상도 | **640×360** | 3배 = 1920×1080, 4배 = 2560×1440. 항상 정수배로 확대한다 |
| PPU (Pixels Per Unit) | **32** | 모든 스프라이트에 같은 값을 쓴다. 에셋마다 다르게 두지 않는다 |
| 카메라 | Orthographic, 크기 5.625 | 360 ÷ 2 ÷ 32. 화면 높이가 11.25 유닛이다 |
| 안전 영역 | 가운데 640×360 | 캐릭터 위치, 전투, UI 같은 중요한 요소는 이 안에 둔다 |

- 카메라에는 URP의 Pixel Perfect Camera(기준 해상도 640×360, PPU 32)를 붙여 픽셀이 정수배로만 보이게 한다. 화면은 코드로 조립하므로(`architecture.md`의 "화면: 코드로 조립한다") 이 설정도 코드에서 한다.
- UI의 `CanvasScaler`는 기준 해상도 640×360, Scale With Screen Size, 높이에 맞춤(Match = 1)으로 둔다. UI 스프라이트도 같은 픽셀 크기 기준으로 그린다.

## 화면 비율

폰은 16:9보다 가로로 긴 경우가 많다. 높이 360을 고정하고 폭이 늘어난다.

| 비율 | 폭 |
| --- | --- |
| 16:9 | 640 |
| 19.5:9 | 780 |
| 20:9 | 800 |

- 늘어난 양옆에는 배경만 보이게 한다. 중요한 요소는 가운데 640 안에 둔다.
- UI는 화면 가장자리에 앵커로 붙이고, 노치가 있는 기기를 위해 `Screen.safeArea` 안에 배치한다.

## 에셋별 캔버스 크기

| 종류 | 캔버스 (px) | 비고 |
| --- | --- | --- |
| 주인공 | 48×48 | 몸은 키 32px 정도, 남는 칸은 검 휘두르는 동작 여유분. 더 크게 보이려면 64×64 |
| 일반 몬스터 | 48×48 | 사람형이라 주인공과 같은 캔버스·같은 키로 그린다 |
| 보스 | 96×96 ~ 128×128 | 화면 높이의 1/3 정도 |
| 검기·매화 이펙트 | 64×64 ~ 96×96 | |
| 아이콘 (재화, 강화 항목 등) | 16×16 또는 32×32 | UI에서 2배, 3배 같은 정수배로 확대 |
| UI 패널·버튼 | 작게 그리고 9-slice로 늘림 | 예: 24×24 테두리 |
| 배경 | 높이 360, 폭 800 이상 | 또는 가로로 이어 붙여 반복되는 타일형. 시차 스크롤용이면 레이어(먼 산, 중간, 가까운 땅)로 나눈다 |

실행해 보고 전체가 작거나 크면 에셋을 하나씩 키우지 않고 기준 해상도를 바꾼다 (예: 480×270으로 낮추면 모두 1.33배 커 보인다). 특정 종류만 키워야 하면 그 에셋을 새 캔버스 크기로 다시 그린다. 한 에셋만 배율로 키우면 그 에셋만 픽셀 크기가 달라져 다른 에셋과 섞였을 때 어색하다.

에셋이 아직 없을 때 쓰는 대체 표시(단색 사각형 등)도 위 크기에 맞춰 만든다. 예: 주인공 대체 표시는 48×48px = 1.5×1.5 유닛.

## 그리는 규칙

- 같은 애니메이션의 프레임은 캔버스 크기와 피벗을 모두 같게 한다. 시트로 묶을 때는 한 칸 크기를 통일한다.
- 피벗: 캐릭터·몬스터는 발 아래 가운데(Bottom Center), 이펙트·아이콘은 가운데(Center).
- 크기를 바꿀 때는 Nearest Neighbor로 정수배만 쓴다. 0.5배, 1.5배처럼 정수가 아닌 배율로 줄이거나 늘리지 않는다.
- AI로 생성한 이미지는 격자가 맞지 않는 경우가 많다. 목표 캔버스 크기로 Nearest Neighbor 축소를 하고 팔레트를 정리(색 수 줄이기)한 뒤 넣는다.
- 원본(큰 크기, 작업 파일)은 게임 폴더(`Assets/`) 밖에 따로 보관하고, `Assets/`에는 게임용 크기만 넣는다.

## 가져오기 설정

| 항목 | 값 |
| --- | --- |
| Texture Type | Sprite (2D and UI) |
| Pixels Per Unit | 32 |
| Filter Mode | Point (no filter) |
| Compression | None |
| Generate Mip Maps | 끔 |

가져오기 설정은 `.meta` 파일에 저장된다. 루프 안의 에이전트는 `.meta`의 가져오기 설정을 직접 고치지 않는다. 설정은 사람이 에디터에서 하거나, 이를 자동으로 맞추는 작업을 따로 만든다.
