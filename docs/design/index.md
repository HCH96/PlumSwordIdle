# 기획 문서 색인

사람이 쓰고 읽는 게임 기획 원본이다. 기능별 확정 사양이 아니다.

- **작업 문서를 구현하는 에이전트는 이 폴더를 읽지 않는다.** 구현 기준은 `docs/spec/`의 사양이다.
- 기획 스킬(`plan-feature`)은 아래 표에서 기획할 기능에 닿는 절만 골라 읽는다. 문서 전체를 읽지 않는다.
- 내용이 서로 다르면 단계 번호가 큰 문서가 그 단계부터의 규칙이다 (예: 공격 속도 강화는 1·2단계에만 있고 3단계에서 내공 강화로 바뀐다).
- `(임시)`가 붙은 수치는 플레이해 본 뒤 바뀔 수 있다.
