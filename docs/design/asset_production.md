# 매화검 키우기 — 에셋 제작 정리

사용자가 AI 도구로 제작해 제공할 게임 에셋을 정리하는 문서다. 이 목록은 제작 준비용이며 구체적인 그림체, 크기, 프레임 수와 파일 형식은 아직 확정하지 않았다. 기능별 확정 사양이나 작업 문서는 아니다.

## 제작 방향과 우선순위

- 2D 픽셀아트, 화산파 무협 분위기. 화면 위쪽의 횡스크롤 전투와 아래쪽 강화 UI에 사용한다.
- 제자·배경·일반 상대·보스의 외형과 공격·스킬 애니메이션은 사용자가 AI 도구로 제작해 제공할 계획이다. 스테이지별 실제 제작 범위와 제공 시점은 아직 정하지 않았다.
- **1단계:** 임시 이미지나 단색 도형으로 전투를 먼저 확인할 수 있다. 에셋이 준비되면 교체한다.
- **2단계:** 다섯 스테이지의 테마를 알아볼 수 있는 외형·배경과 전투 애니메이션을 연결한다.
- **3단계:** 제자의 자동 발동 스킬 하나에 필요한 에셋을 추가한다.
- **4단계:** 시간과 결과를 보고 추가 연출·UI 아트를 다듬는다. 보스 등장 카메라와 애니메이션은 후보이며 필수로 확정하지 않았다.

## 제자 캐릭터

| 에셋 | 용도 | 상태 |
| --- | --- | --- |
| 화산파 제자 | 플레이어 캐릭터 기본 외형. 횡스크롤 화면에서 앞을 향해 전진 | 제작 예정. 세부 디자인 미정 |
| 이동 애니메이션 | 적을 향해 달릴 때 | 제작 필요 여부와 프레임 수 확인 |
| 기본 공격 애니메이션 | 앞쪽 범위의 적을 검으로 공격할 때 | 제작 예정. 세부 연출 미정 |
| 이십사수매화검법 애니메이션·효과 | 3단계에서 자동 발동하는 전방 검기 스킬 | 구체적인 연출과 프레임 수 미정 |
| 경지별 오오라 이펙트 | 3단계에서 삼류부터 초절정까지 각 경지의 캐릭터 주변에 표시 | 나중에 AI에 제작을 요청하고 결과를 보고 사용 여부 결정. 이미지 에셋 또는 Unity 이펙트 중 방식 미정 |
| 대기·피격·패배 모션 | 멈춤, 피해, 패배를 보여 주는 선택적 연출 | 우선순위와 필요 여부 미정 |

## 스테이지별 배경과 적

다섯 스테이지 모두 일반 상대 10명과 보스 1명이 나온다. 아래 장소와 상대의 구체적인 모습은 이야기 방향에 따른 **제작 아이디어**이며 확정 디자인이 아니다.

| 스테이지 | 배경 아이디어 | 일반 상대 아이디어 | 보스 아이디어 |
| --- | --- | --- | --- |
| 1. 종남파 | 종남의 연무장 | 종남 제자 | 종남의 대표 제자 |
| 2. 개방 | 마을과 객잔 주변 | 개방의 대련 상대 | 개방의 고수 |
| 3. 남궁세가 | 정원이나 연무장 | 남궁세가 무사 | 남궁의 검객 |
| 4. 마교 전초전 | 불탄 산길 또는 요새 앞 | 마교 교도 | 전초전 지휘관 |
| 5. 천마 | 전쟁터 또는 전각 앞 | 마교 정예 | 천마 |

- **배경:** 제자가 전진할 때 왼쪽으로 흘러가고 이미지가 반복되어 이어지는 길처럼 보여야 한다. 연결부가 어색하지 않게 만들 수 있는지 제작 전에 확인한다.
- **일반 상대:** 스테이지별 모습과 공격 애니메이션. 2단계까지는 모두 근거리 공격을 사용한다.
- **보스:** 스테이지별 모습과 공격 애니메이션. 2단계까지는 고정형이며 별도의 특수 공격 패턴이 없다.
- 대기·이동·피격·패배 모션의 상세 목록과 여러 캐릭터 간 재사용 여부는 나중에 제작 범위를 정할 때 결정한다.
- 천마의 4단계 등장 연출을 위한 별도 애니메이션은 후보이며 아직 확정하지 않았다.

## UI: 코드로 먼저 만들 수 있는 것

Unity 기본 UI와 글자, 단색 도형으로 우선 만들 수 있으므로 **처음부터 별도 이미지 제작이 필요한 것은 아니다.** 디자인을 맞추고 싶을 때 아래 선택적 에셋을 추가한다.

| UI | 현재 계획 | 선택적으로 만들 수 있는 에셋 |
| --- | --- | --- |
| 캐릭터·일반 상대 체력 바 | 머리 위의 작은 초록색·빨간색 바 | 바의 테두리와 채움 이미지 |
| 스테이지 진행 바·보스 체력 바 | 일반 상대 처치 진행도에서 보스 체력 바로 전환 | 공통 프레임, 채움 이미지, 보스 이름판 |
| 금화 표시 | 보유 금화를 글자와 함께 표시 | 금화 아이콘 |
| 능력치 강화 버튼 | 능력치 이름, 강화 단계, 비용과 사용 불가 상태 표시 | 버튼 프레임, 공격력·체력·공격 속도 아이콘 |
| 스테이지 안내 | 이름과 짧은 이야기 표시 | 문파 표식이나 안내 패널 장식 |
| 오프라인 보상 창 | 시간·금화와 `받기` 버튼 표시 | 창 프레임, 보상 아이콘 |
| 회차·스테이지 표시 | 천마 처치 후 다음 회차와 스테이지 표시 | 회차 표시 장식이나 문파 표식 |

- 메인 메뉴와 설정 메뉴의 세부 구성은 아직 정하지 않았다. 메뉴용 에셋은 화면 기획이 정해진 뒤 목록에 추가한다.
- 페이드인·페이드아웃은 단색 화면의 투명도를 바꾸는 방식으로 만들 수 있다. 별도 이미지가 필수는 아니다.

## 제작 전에 함께 정할 것

- 제자와 적의 화면 크기, 배경 해상도·반복 방식, 픽셀 밀도.
- 스프라이트 파일 형식과 투명 배경, 프레임 배치와 애니메이션 속도.
- 각 캐릭터에 필요한 모션 목록과 제공 시점. 스킬 애니메이션은 스킬 동작을 정한 뒤 상세화한다.
- 실제 에셋 크기에 맞춰 1단계의 공격 거리·이동 속도·체력 바 위치를 검증하고 조정한다.
