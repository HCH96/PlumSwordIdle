# 게임 전체 기획

이 문서는 프로젝트의 범위와 전체 마일스톤을 안내하는 기획 기록이다. 기능별 확정 사양이나 작업 문서는 아니다.

## 프로젝트 범위
- 1주일짜리 프로젝트로, 기능과 콘텐츠를 크게 확장하지 않는다.
- 많은 종류의 무공이나 스킬보다 전투, 보상, 강화, 스테이지 진행이 이어지는 핵심 흐름에 집중한다.
- 필수 범위인 경지 돌파와 저장·오프라인 보상도 작은 형태로 기획한다.
- 제자·배경·일반 몬스터·보스의 외형과 공격·스킬 애니메이션은 사용자가 AI 도구로 제작해 제공할 계획이다. 제작 대상과 전달 시점, 사용 가능한 애니메이션은 기획과 제작 진행에 따라 확인한다.

## 마일스톤
마일스톤은 기능 하나를 완성하는 순서가 아니라 여러 기능을 필요한 만큼 묶어 게임 전체의 진행 정도를 확인하는 기준이다. 각 단계의 결과를 직접 확인하고 다음 단계에 반영한다.

1. **핵심 재미 검증**: 일반 몬스터와 보스로 구성된 간단한 스테이지에서 자동 전투 → 금화 획득 → 강화 → 재도전이 이어지는 프로토타입을 플레이한다. 화면과 수치는 간단한 임시 형태로 시작한다.
2. **방치형 진행 완성**: 보스와 스테이지 진행을 발전시키며 저장·불러오기와 오프라인 보상을 연결한다.
3. **성장과 목표 확장**: 경지 돌파와 성장 보너스를 추가하고 전투·강화 수치를 조정한다. 자동 발동 스킬 하나와 내공 강화 하나를 도입하고 공격 속도 강화는 제거하는 방향을 계획한다.
4. **게임 완성도와 안정화**: 준비된 에셋 적용, UI 개선, 밸런스 조정과 전체 흐름 검증을 수행한다. 보스 등장 연출은 이 단계의 후보로 둔다. 포트폴리오 기록은 사용자가 별도로 진행한다.

## 이후 마일스톤에서 계획한 요소

스테이지는 테마마다 배경과 적이 달라진다. 화산파 제자가 대련하며 성장하고 마교의 위협을 알게 된 뒤 전쟁에 참여한다. 총 5개 스테이지는 **종남파 → 개방 → 남궁세가 → 마교 전초전 → 천마** 순서이며, 천마 처치 후에는 1스테이지부터 다시 반복하고 캐릭터는 계속 성장한다. 환생 시스템은 만들지 않는다. 반복 시 세부 규칙은 2단계 기획에서 정한다. 1단계의 끝없이 증가하는 스테이지는 프로토타입 범위다.

환생을 제외한 이유: 현재는 초기화 후 얻는 보상의 매력이 충분하지 않고 이전보다 약해지는 느낌이 들 수 있다. 추후 모든 작업을 마치고 시간이 남아 새로운 스킬이나 검 같은 수집 요소가 생기면 재검토할 가능성은 있으나 매우 낮다. 현재 범위에는 환생과 해당 수집 기능을 추가하지 않는다.
### 3단계: 성장

- 1단계에서는 공격 속도 강화를 유지하되, 3단계에서는 공격 속도 강화를 아예 제거하고 내공 강화로 대체한다.
- 자동 발동 스킬 하나를 추가하고, 내공 강화로 스킬 피해량을 높인다. 스킬과 내공 강화는 각각 하나만 둔다.
- 3단계를 시작할 때 사용자가 기존 2단계 저장 데이터를 지우고 새로 시작한다. 기존 강화 환불이나 저장 데이터 이전 코드는 만들지 않는다. 내공·스킬의 세부 사항은 3단계 기획을 따른다. 원거리 몬스터는 1단계 범위 밖이며 이후 추가할 후보다.

### 4단계 후보: 보스 등장 연출

- 보스가 화면 밖에 등장한 뒤 카메라가 보스 쪽으로 이동하고 보스 등장 애니메이션을 재생한다. 이어 카메라가 제자에게 돌아오면 제자가 보스를 향해 달려가 싸운다. 이 카메라 연출은 1단계 범위에는 넣지 않는다.
- 시간이 부족하면 보스 이름 표시와 짧은 등장 애니메이션만 추가하는 방안도 검토한다.
