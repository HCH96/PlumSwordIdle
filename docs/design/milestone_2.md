# 2단계 기획 — 방치형 진행 완성

이 문서는 2단계 기획을 위한 시작 문서다. 아직 기능별 확정 사양이나 루프에 투입할 작업 문서가 아니며, 구체적인 규칙은 앞으로 기획한다.

1단계와 다른 규칙을 정하면 이 문서에 추가·변경 사항과 이유를 기록한다.

## 목표와 범위

- 1단계의 전투·금화·강화·스테이지 흐름을 바탕으로 방치형 진행을 발전시킨다.
- 보스와 스테이지 진행을 필요한 범위에서 발전시킨다.
- 저장·불러오기와 오프라인 보상을 추가한다.
- 1주일짜리 프로젝트에 맞게 구현 범위를 작게 유지한다.

## 1단계에서 이어받는 내용

- 1단계에는 일반 몬스터 10마리와 보스, 자동 스테이지 진행과 실패 시 같은 스테이지 재도전이 포함된다. 구체적인 현재 규칙은 1단계 기획을 따른다.
- 1단계에는 저장·불러오기와 오프라인 보상이 없다. 게임을 종료하면 진행 상태가 초기화된다.

## 추가하거나 변경할 기능

### 저장과 불러오기

- 현재 스테이지, 보유 금화, 공격력·체력·공격 속도 강화 단계와 마지막 저장 시각을 기기에 저장한다. 저장 시각은 오프라인 보상 계산에 사용한다.
- 강화나 스테이지 성공 등 중요한 변화가 생겼을 때와 게임을 종료하거나 앱이 백그라운드로 전환될 때 저장한다. 구체적인 변화별 저장 시점은 아직 정하지 않았다.
- 몬스터 보상 획득이나 강화 구매 등 금화가 바뀔 때 저장한다. 보스 처치 후 다음 스테이지로 넘어갈 때도 저장한다.
- 다시 시작할 때 저장된 현재 스테이지의 시작 지점에서 체력을 전부 회복하고 시작한다. 중간에 처치한 몬스터 수와 남은 체력은 복원하지 않는다. 금화와 강화 단계는 유지한다.
- 저장 데이터가 없으면 1스테이지, 금화 0, 세 강화 단계 Lv.0으로 시작한다.
- 기기에 저장하며 계정 연동과 클라우드 저장은 범위 밖이다.
- 저장이 실패하면 오류를 표시하고 기존 저장 데이터를 유지한 채 다시 저장을 시도한다. 새 데이터는 안전하게 기록한 뒤 기존 데이터를 교체하며, 기록 중 문제가 생기면 기존 데이터를 유지한다.
- 저장 데이터가 손상되면 자동으로 덮어쓰지 않고 오류를 표시한다. 사용자가 `새로 시작`을 선택하면 초기 상태로 시작한다. 저장 데이터가 없는 첫 실행은 오류가 아니다.

### 오프라인 보상

- 오프라인 보상은 금화만 지급한다. 오프라인 중 스테이지 진행이나 강화는 하지 않는다.
- 마지막으로 기록한 시각과 현재 시각의 차이를 계산하며, 종료 전 저장된 현재 스테이지의 일반 몬스터 한 마리 처치 보상을 기준으로 한다.
- 오프라인 10초당 일반 몬스터 한 마리분의 금화를 지급하고, 인정 시간은 최대 8시간으로 제한한다. **10초와 8시간은 이후 수정할 임시값**이다. 예: 1스테이지에서 10분 경과 시 600금화다.
- 다시 켜면 보상 창에 지난 시간과 받을 금화를 보여 주고, `받기`를 누르면 지급한다.
- 지급한 뒤 보상 기준 시각을 갱신해 같은 시간에 대한 보상을 중복 지급하지 않는다. 시각 갱신과 저장의 상세 처리 순서는 아직 정하지 않았다.
- 10초 미만의 나머지는 보상으로 계산하지 않는다. 예: 25초는 20초분을 지급한다. 전체 경과 시간이 10초 미만이면 보상 창 없이 게임을 시작한다.
- 기기 시간이 마지막 기록 시각보다 이전이면 경과 시간을 0으로 처리하고 보상하지 않는다.
- 보상 창이 열린 동안 전투와 강화를 멈추고, 보상을 받은 뒤 시작한다. 앱이 백그라운드에서 돌아올 때도 동일하게 처리한다.
- 백그라운드에서 돌아오면 저장된 현재 스테이지의 시작 지점으로 돌아가 체력을 전부 회복하고, 보상 창을 표시한 뒤 재시작한다. 처치 진행도와 남은 체력은 복원하지 않는다.
- 금화 지급과 보상 기준 시각 갱신을 함께 저장해 처리 중 앱이 종료되어도 같은 시간의 보상을 다시 받지 않도록 한다. 받을 금화가 없어 보상 창을 표시하지 않는 경우에도 이후 보상 계산을 위해 기준 시각을 갱신한다.
- 오프라인 보상 저장이 실패하면 보상 창에 오류와 재시도 방법을 표시한다. 저장 확인 전에는 중복 지급되지 않게 처리한다.
- 최대 인정 시간을 초과하면 창에 실제 경과 시간과 보상 적용 시간을 함께 표시한다. 예: 1스테이지에서 9시간이 지났다면 8시간을 적용해 28,800금화를 지급한다 (10초·8시간 임시값 기준).

### 보스와 스테이지 진행

- 스테이지마다 문파 등 테마가 달라지고, 테마에 맞게 배경과 몬스터·보스가 함께 바뀐다. 화산파 제자가 다른 세력과 대련하며 성장하고, 마교의 위협을 알게 된 뒤 전쟁에 참여해 마지막에 천마와 대결하는 이야기 흐름을 정했다.
- 총 5개 스테이지로 정한다: **종남파 친선 대련 → 개방에서 대련과 마교의 움직임 파악 → 남궁세가 검술 대련 → 마교 전초전 → 천마와 최종 대결**. 각 스테이지의 구체적인 배경과 적의 모습은 아직 정하지 않았다.
- 대련 구간의 상대는 종남의 제자, 개방의 고수, 남궁의 검객 등으로 표현하고 전쟁 구간은 마교 세력과 싸우는 방향을 구상한다. 대련 구간의 처치 표현은 `대련에서 승리` 등으로 바꿀 수 있다.
- 제자·배경·일반 몬스터·보스의 외형과 공격·스킬 애니메이션은 사용자가 AI 도구로 제작해 제공할 계획이다. 스테이지별 에셋 범위와 제공 시점은 아직 정하지 않았다.
- 각 스테이지는 일반 상대 10명과 보스 1명으로 구성한다. 보스를 이기면 종남 → 개방 → 남궁 → 마교 전초전 → 천마 순서로 자동 진행한다.
- 2단계에서는 테마에 관계없이 적은 근거리 공격을 사용하고, 보스에 별도 특수 공격 패턴을 두지 않는다. 능력치는 스테이지가 올라갈수록 증가한다.
- 테마별 배경·일반 상대·보스 외형과 제공된 공격 애니메이션을 연결한다. 제자의 자동 발동 스킬과 그 애니메이션은 3단계에서 추가한다.
- 스테이지에 처음 진입하면 이름과 짧은 한두 문장으로 상황을 전달한다. 예: `종남파 — 화산의 제자가 종남의 연무장에서 친선 대련에 나선다.` 2단계에는 긴 대화나 컷신을 넣지 않는다.
- 소개는 전투 화면 위에 스테이지 이름과 문구를 3초 (임시) 표시한 뒤 자동으로 없앤다. 표시 중에는 전투와 이동을 멈추고, 소개가 사라지면 전투를 시작한다. 실패 후 같은 스테이지를 재도전할 때는 다시 표시하지 않는다.
- 스테이지 소개는 첫 번째 진행에서만 표시하고 반복할 때는 표시하지 않는다. 게임 재실행·불러오기 후 이미 본 소개를 어떻게 처리할지는 확인이 필요하다.
- 스테이지 소개 문구:
  - 종남파: “화산의 제자, 종남에서 첫 대련에 나선다.”
  - 개방: “개방의 시험을 통과하고 마교의 움직임을 듣는다.”
  - 남궁세가: “다가올 싸움에 대비해 남궁의 검과 겨룬다.”
  - 마교 전초전: “마교의 군세를 막기 위한 전투가 시작된다.”
  - 천마: “전쟁의 끝에서 천마와 마주한다.”
- 천마를 쓰러뜨리면 게임을 영구적으로 종료하지 않고 1스테이지부터 다시 반복한다. 캐릭터는 계속 성장하며 환생 시스템은 없다.
- 천마 처치 보상을 받은 뒤 기존 스테이지 전환처럼 페이드하고 1스테이지 종남파부터 자동 진행한다. 금화, 능력치 강화, 경지 등 지금까지의 성장은 초기화하지 않고 유지한다.
- 테마는 다시 종남파부터 나오지만 반복할수록 적은 계속 강해지고 보상도 증가한다. **1스테이지로 돌아왔을 때 적이 강해지는 방식은 이후 수정될 수 있다.** 반복에 따른 정확한 수치 공식은 아직 정하지 않았다.
- `2회차 · 스테이지 1 종남파`처럼 회차와 스테이지를 표시한다. 반복 중에도 기존 오프라인 보상 규칙을 적용한다. 회차에 따른 보상 계산 방식과 저장할 회차 정보는 구체화가 필요하다.
- 기존에 정한 `클리어 화면에서 전투 중단·클리어 상태 유지·클리어 이후 오프라인 보상 없음`은 위 반복 진행 결정으로 대체한다.
- 1단계의 끝없이 증가하는 임시 스테이지를 2단계에서 5개 테마가 순환하는 구성으로 발전시킨다.
- 4단계 후보인 보스 등장 카메라 연출은 게임 전체 기획을 참고한다.

### 시작 화면과 기본 메뉴

- 2단계에서 게임 제목 `매화검 키우기`와 시작 버튼이 있는 시작 화면을 추가한다.
- 저장 데이터가 없으면 `게임 시작`을 표시하고, 누르면 1스테이지를 시작한다. 저장 데이터가 있으면 `이어하기`를 표시하고, 누르면 저장된 스테이지를 불러온다.
- `이어하기`를 누른 뒤 오프라인 보상이 있으면 보상 창을 보여 주고, 보상을 받은 다음 전투를 시작한다.
- 시작 화면과 게임 중 모두 설정을 열 수 있게 한다. 2단계 설정 범위는 배경음악·효과음 음량으로 한다. 소리가 아직 준비되지 않았을 때 UI를 먼저 넣을지는 추후 정한다.
- 게임 중 설정 메뉴에서 게임을 종료할 수 있으며, 종료 전에 저장을 시도한다.
- 전투 화면의 설정 버튼을 누르면 설정 창이 열린다. 창이 열려 있어도 뒤쪽 전투와 이동은 멈추지 않고 계속 진행한다.
- 배경음악과 효과음 음량은 각각 조절하며 설정값을 기기에 저장한다.
- 게임 중 설정에서 시작 화면으로 돌아갈 수 있다. 돌아가기 전에 현재 진행 상황을 저장한다.
- 시작 화면으로 돌아가면 전투를 멈춘다. 저장에 실패하면 오류를 표시하고 시작 화면으로 이동하지 않으며 다시 저장을 시도할 수 있다.
- 시작 화면의 `이어하기`로 돌아오면 저장된 스테이지의 시작 지점에서 체력을 전부 회복하고 시작한다.
- **시작 화면에 머문 시간은 오프라인 보상 계산에 포함하지 않는다.** 시작 화면에서 이어하기로 돌아올 때 이 시간이 보상에 합산되지 않도록 보상 기준 시각을 처리한다. 앱 종료·백그라운드 전환 후 복귀에 대한 기존 오프라인 보상 규칙은 유지한다.

## 기능 간 연결과 선행 관계

- 저장할 값과 복원할 방식은 1단계의 각 기능과 연결해 정해야 한다.
- 오프라인 보상이 참조하는 진행 상태와 지급할 보상은 규칙을 정한 뒤 연결한다.
- 실제 연결 지점과 작업의 선행 관계는 기능별 사양과 작업 문서를 만들 때 확정한다.

## 마일스톤 달성 기준

- 종남부터 천마까지 다섯 스테이지를 정해진 순서로 진행하고, 각 테마의 배경과 상대를 구분할 수 있다.
- 시작 화면의 처음 시작·이어하기, 음량 설정, 시작 화면 복귀와 게임 종료가 동작한다.
- 현재 스테이지, 금화, 강화 상태를 저장하고 다시 실행해 이어갈 수 있다.
- 오프라인 시간에 따른 금화를 표시·지급하고, 같은 시간에 대한 보상은 중복 지급하지 않는다.
- 천마를 처치하면 1스테이지부터 반복 진행하며, 게임을 다시 실행한 뒤에도 정해진 저장 규칙에 따라 진행을 이어간다. 반복 시 세부 기준은 기획 후 구체화한다.
- 저장 실패나 손상 데이터를 사용자에게 알리고 정한 방식으로 처리한다.
- 주요 계산과 상태 전환의 자동 테스트가 통과하고, 처음 시작부터 클리어까지 직접 플레이해 확인한다.

## 미결 사항과 결정 기록

- 저장 재시도의 세부 방식과 오프라인 보상 저장의 원자적 처리 등 구현을 위한 세부 규칙은 아직 정하지 않았다.
- 회차 저장·복원 방식, 반복 시 적 능력치와 보상 공식, 오프라인 보상의 회차별 계산은 아직 정하지 않았다.
