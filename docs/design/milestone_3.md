# 3단계 기획 — 성장과 목표 확장

이 문서는 3단계의 기획 진행 기록이다. 기능별 확정 사양이나 루프에 투입할 작업 문서는 아니다.

## 목표와 현재 방향

- 경지 돌파와 성장 보너스로 무협다운 성장의 목표를 만든다.
- 1단계의 공격 속도 강화를 제거하고 내공 강화로 대체한다.
- 자동 발동 스킬 하나를 추가하며, 내공 강화가 해당 스킬의 피해량을 높인다.
- 환생 시스템은 만들지 않는다. 천마를 처치하면 금화·강화·경지 등 성장을 유지하고 1스테이지부터 계속 반복한다. 반복 시 세부 규칙은 2단계에서 정한다.
- 3단계를 시작할 때 사용자가 기존 2단계 저장 데이터를 지우고 처음부터 다시 시작한다. 기존 데이터 이전, 공격 속도 강화 환불과 호환 코드는 만들지 않는다.
- 3단계에서는 공격 속도 강화가 없으며 제자의 기본 공격 간격은 1초 (임시)로 시작한다. 자동 발동 스킬의 구체적인 규칙은 아래를 따른다.

## 경지 돌파

- 경지는 `삼류 → 이류 → 일류 → 절정 → 초절정`의 5단계이며 처음 시작할 때는 삼류다.
- 필요한 금화를 모아 돌파 버튼을 직접 누른다. 금화 외에 별도의 스테이지 조건은 없다.
- 돌파 비용은 삼류 → 이류 200금화, 이류 → 일류 500금화, 일류 → 절정 1,000금화, 절정 → 초절정 2,000금화다 (모두 임시).
- 공격력과 최대 체력의 경지별 누적 보너스는 삼류 +0%, 이류 +10%, 일류 +20%, 절정 +30%, 초절정 +40%다 (모두 임시). 각 보너스는 해당 능력치의 기본값과 일반 강화 증가량의 합계에 적용하고, 소수점은 내림한다.
- 돌파로 최대 체력이 증가하면 증가분만큼 현재 체력도 증가한다. 예: 일반 강화를 포함한 공격력 10, 최대 체력 100에서 이류로 돌파하면 공격력 11, 최대 체력 110이 된다.
- 일반 공격력·체력 강화 후에도 각 능력치의 기본값과 일반 강화 증가량의 합계에 현재 경지 보너스를 적용하고 소수점을 내린다. 체력을 강화할 때 현재 체력은 강화 전후 최종 최대 체력의 차이만큼 증가한다.
- 예: 이류에서 체력 강화 1회 시 최대 체력은 `floor(100 × 1.1) = 110`에서 `floor(120 × 1.1) = 132`로 오르고, 현재 체력도 22 증가한다. 공격력 강화 1회 시 `floor((10 + 2) × 1.1) = 13`이다. 스킬은 이처럼 경지 보너스가 적용된 최종 공격력을 기준으로 계산한다.
- 초절정에서는 더 이상 돌파할 수 없고 버튼에 `최대`를 표시한다. 천마 처치 후 스테이지를 반복해도 경지를 유지한다.
- 각 경지마다 캐릭터 주변에 오오라 이펙트를 표시한다. 나중에 AI에게 제작을 요청하고 결과가 마음에 들면 그대로 사용한다. 이미지 에셋으로 만들지 Unity에서 이펙트로 구현할지와 경지별 외형은 아직 정하지 않았다.

## 자동 발동 스킬

- 스킬 이름은 **이십사수매화검법**이다. 제자 앞쪽에 검기를 날려 범위 안의 모든 적에게 같은 피해를 주는 스킬 하나를 추가한다. 스킬 범위는 앞쪽 2 유닛 (임시), 피해는 현재 공격력의 200% (임시)다.
- 스킬을 사용한 뒤 5초 (임시)가 지나면 다시 사용할 수 있다. 적이 없으면 준비된 상태로 기다린다.
- 기본 공격과 스킬이 겹치지 않도록, 제자가 기본 공격을 할 차례에 스킬이 준비되어 있으면 기본 공격 대신 스킬을 사용한다. 스킬이 준비되지 않았으면 기본 공격을 한다. 스킬 준비가 끝나더라도 다음 공격 차례까지 기다린다.
- 스킬의 재사용 대기 시간은 기본 공격 간격과 별도로 관리한다. 스킬 애니메이션은 사용자가 제작해 제공할 계획이며 준비 전에는 임시 이펙트를 사용할 수 있다.
- 3단계에서는 스킬이 별도의 습득 과정 없이 처음부터 사용 가능하다. 게임을 다시 켤 때 스킬 재사용 대기는 복원하지 않고 사용 가능한 상태로 시작한다. 스테이지 성공·실패 후에는 기본 공격과 스킬 모두 사용 가능한 상태로 준비한다.
- 스킬을 사용하는 공격 타이밍에 범위 안의 적에게 즉시 피해를 주고, 다음 공격까지 기본 공격 간격인 1초 (임시)를 기다린다. 적은 스킬 사용 중에도 기존 간격에 따라 공격한다. 동시 처치에는 기존 전투 규칙을 적용한다.
- 내공 강화는 Lv.0에서 시작하며 첫 비용은 20금화, 강화할 때마다 다음 비용이 5금화씩 증가한다 (임시). 별도의 강화 상한은 없다.
- 내공 강화 한 단계당 스킬 피해 배율을 10%p (임시) 높인다. Lv.0은 현재 공격력의 200%, Lv.1은 210%, Lv.2는 220%다. 현재 공격력에는 경지 보너스를 포함한다.
- 스킬의 최종 피해량은 소수점을 내림한다. 예: 현재 공격력이 10이고 내공이 Lv.1이면 `floor(10 × 2.1) = 21` 피해다.

## 저장과 반복 진행

- 현재 경지와 내공 강화 단계를 금화·스테이지·회차·다른 강화 단계 등과 함께 새 저장 데이터에 기록하고 복원한다.
- 천마를 이기고 종남파로 돌아와도 경지와 내공 강화 단계는 유지한다.

## 3단계 화면

- 기존 공격 속도 강화 버튼을 없애고 같은 자리에 내공 강화 버튼을 표시한다. 다른 강화 버튼처럼 내공 단계와 다음 강화 비용을 표시한다. 예: `내공 Lv.1 / 25금화`.
- 현재 경지 이름을 전투 화면에 표시한다. 예: `경지: 이류`.
- 돌파 버튼에 현재 경지와 다음 돌파에 필요한 금화를 표시한다. 금화가 부족하면 어둡게 표시하고 누를 수 없게 한다.
- 초절정에서는 돌파 버튼의 비용 대신 `최대`를 표시하고 누를 수 없게 한다.
- 1차 구현에서는 스킬을 자동 발동하며 별도 스킬 버튼이나 대기 시간 표시는 두지 않는다.

## 3단계 마일스톤 달성 기준

- 금화를 소비해 삼류부터 초절정까지 돌파하고 단계별 공격력·체력 보너스가 적용된다.
- 현재 경지와 돌파 비용이 표시되고, 경지에 맞는 오오라를 볼 수 있다. 실제 오오라 제작 전에는 임시 이펙트로 기능을 먼저 확인할 수 있다.
- 공격 속도 강화 대신 내공을 강화하고, 내공 단계에 따라 스킬 피해가 증가한다.
- 공격 차례에 이십사수매화검법이 준비돼 있으면 기본 공격 대신 스킬이 발동한다.
- 게임을 다시 켜거나 천마 이후 스테이지를 반복해도 경지와 내공이 유지된다.
- 경지·내공·스킬 계산과 상태 전환의 자동 테스트가 통과하고, 직접 플레이해 효과를 확인한다.

## 미결 사항

- 경지 돌파 수치의 밸런스와 오오라 외형.
- 내공과 스킬의 임시 수치에 대한 밸런스 검증.
- 경지·내공 저장과 스킬 대기 초기화의 구현 세부 사항.
- 반복 플레이와 경지·내공·스킬의 성장 및 저장 연결.
- 3단계 기능 간 구체적인 C# 연결 지점.
