# 소리 기록

[audio.md](../audio.md) 사양의 이력이다. 구현에 필요한 규칙은 사양 문서에 모두 있으므로 **구현하는 에이전트는 읽지 않아도 된다.** 기획 스킬(`plan-feature`)이 이미 정한 것을 다시 묻지 않으려고 읽는다.

## 결정 기록

| 질문 | 답 | 방식 |
| --- | --- | --- |
| 파일·음량 연결 지점·이벤트를 받을 사양 | 사용자가 처음 요청에서 정함 (배경음악 4곡 확정, 효과음 14종 미확정, `VolumeSettings` 사용) | 사용자 지정 |
| 보스곡 시작 시점 | 보스가 배치되는 가려진 순간 | 사용자 선택 (추천안) |
| 보스 격파·패배 뒤 곡 | 가려진 순간 새 상태의 곡 (`TrackFor` 하나로) | 사용자 선택 (추천안) |
| 곡을 바꾸는 방식 | 교차 페이드 1초 | 사용자 선택 (추천안), 임시값 |
| 같은 곡으로 바꿀 때 | 이어 틀기 | 사용자 선택 (추천안) |
| 스테이지 시작 전(보상 창·손상 창) 곡 | `battle_normal` | 직접 정함 |
| `sword_swing`·`attack_hit` | 기본 공격 피해 순간에 둘 다 | 사용자 선택 (추천안), 임시 |
| 스킬 때 기본 공격음 | `plum_sword_skill`이 대신 | 사용자 선택 (추천안) |
| `stage_transition` | 구간 사이 페이드 시작 | 사용자 선택 (추천안), 임시 |
| 버튼음·강화 불가음 감지 | 소리 기능이 눌린 곳을 직접 봄 (다른 화면 코드 안 고침) | 사용자 선택 (추천안) |
| 버튼음 시점 | 누른 곳을 기억했다가 뗄 때 | 사용자 선택 (추천안) |
| 같은 소리 과밀 | 프레임당 하나 + 최소 0.05초 | 사용자 선택 (추천안), 임시값 |
| 동시 재생 상한 | 8개, 넘으면 가장 오래된 것 끊기 | 사용자 선택 (추천안), 임시값 |
| 파일 없음 | 건너뛰고 경로마다 경고 한 번 | 사용자 선택 (추천안) |
| 기본 배율 | 곡 0.6 / 반복 전투음 0.6 / 나머지 1.0 | 사용자 선택 (추천안), 임시값 |
| 설정 음량을 곱하는 법 | 그대로 곱하기 | 사용자 선택 (추천안) |
| 슬라이더 반영과 0 | 바로 반영, 0이면 소리만 0 (효과음은 재생 안 함) | 사용자 선택 (추천안) |
| 창이 떠 있을 때 곡 | 그대로 | 사용자 선택 (추천안) |
| 백그라운드·포커스 잃음 | 곡·효과음 모두 일시정지 후 이어서 | 사용자 선택 (추천안) |
| 루트 다시 만들 때 재생기 | 루트와 함께 새로 (곡 처음부터) | 사용자 선택 (추천안) |
| Core/Game 나누기 | 작은 Core 클래스 여럿 + Game `AudioView` 하나 | 사용자 선택 (추천안) |
