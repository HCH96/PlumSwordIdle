# 회귀와 엔딩 기록

[regression.md](../regression.md) 사양의 이력이다. 구현에 필요한 규칙은 사양 문서에 모두 있으므로 **구현하는 에이전트는 읽지 않아도 된다.** 기획 스킬(`plan-feature`)이 이미 정한 것을 다시 묻지 않으려고 읽는다.

## 결정 기록

| 질문 | 답 | 방식 |
| --- | --- | --- |
| 20분의 기준 | 천마는 첫 판에 거의 못 잡게 강하게, 회귀하며 강해져 천마를 처음 잡으면 게임 끝. 그게 약 20분 (자동 강화 기준) | 사용자 선택 |
| 회귀 시점 | 천마에게 지면 자동 | 추천 수락 |
| 회귀 시 유지되는 것 | 금화·강화·경지 전부 유지, 스테이지와 적 세기만 1회차로 | 추천 수락 |
| 엔딩 뒤 | 엔딩 화면 → 시작 화면 | 추천 수락 |
| 목표 회귀 횟수 | 3번쯤 | 추천 수락 |
| 회귀 연출 | 연출 없이 바로 (평소 실패 전환) | 사용자 선택 |
| 플레이 중 회귀 횟수 표시 | 보여 주지 않음 | 사용자 선택 |
| 플레이 시간 세는 법 | 게임 화면에 있는 시간만 | 추천 수락 |
| 엔딩 뒤 저장 | 저장을 지우고 새 게임 | 추천 수락 |
| 회귀 보너스 | 없음 | 추천 수락 |
| 기존 규칙과의 관계 | `StageProgress`의 `useRegression`(기본 false)으로 켜고, 게임만 켬 | 직접 정함 |
| 저장 판 번호 | 판 2 그대로, 세 줄 추가 | 직접 정함 |
