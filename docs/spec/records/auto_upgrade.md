# 자동 강화 기록

[auto_upgrade.md](../auto_upgrade.md) 사양의 이력이다. 구현에 필요한 규칙은 사양 문서에 모두 있으므로 **구현하는 에이전트는 읽지 않아도 된다.** 기획 스킬(`plan-feature`)이 이미 정한 것을 다시 묻지 않으려고 읽는다.

## 결정 기록

| 질문 | 답 | 방식 |
| --- | --- | --- |
| 자동 강화를 게임 기능으로 넣을까 | 켜고 끄는 버튼이 있는 게임 기능 | 사용자 선택 |
| 무엇을 살까 | 살 수 있으면 셋 중 가장 싼 것부터 바로 | 추천 수락 |
| 언제 사고 같은 비용이면 무엇부터 | 금화가 바뀔 때·잠금이 풀릴 때·켤 때, 무력 → 체력 → 내공 | 추천 수락 |
| 처음 상태와 저장 | 처음엔 켜짐, 켜짐 여부 저장 | 추천 수락 |
| 버튼 위치 | 금화 현판 오른쪽 옆 | 추천 수락 |
