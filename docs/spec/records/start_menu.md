# 시작 화면과 기본 메뉴 기록

[start_menu.md](../start_menu.md) 사양의 이력이다. 구현에 필요한 규칙은 사양 문서에 모두 있으므로 **구현하는 에이전트는 읽지 않아도 된다.** 기획 스킬(`plan-feature`)이 이미 정한 것을 다시 묻지 않으려고 읽는다.

## 결정 기록

| 질문 | 답 | 방식 |
| --- | --- | --- |
| 손상 오류 창을 언제 보여 주는가 | 시작 화면에서 `START`를 누른 뒤 (손상·보상·`Begin` 단계 전체가 시작 버튼 뒤로) | 추천 수락, 2026-11-17 |
| 씬을 나누는가, 시작 화면 복귀 뒤 상태를 어떻게 다시 만드는가 | 씬 하나. `Restart()`처럼 루트를 새로 만들고 파일을 다시 읽는다. 이때 보상은 계산하지 않는다 | 추천 수락, 2026-11-17 |
| 배치 모드에서 시작 화면 | 처음 켤 때는 건너뛰고 바로 시작 (기존 테스트·증거 화면 유지) | 추천 수락, 2026-11-17 |
| `게임 종료`의 저장 실패 | 끄지 않고 오류 문구, 다시 누르면 다시 시도 (`시작 화면으로`와 같은 규칙) | 추천 수락, 2026-11-17 |
| 시작 화면에서 백그라운드 10초 이상 뒤 복귀 | 시작 화면으로 다시 만든다 (보상 다시 계산). 게임 중이면 지금처럼 시작 화면을 건너뛴다 | 추천 수락, 2026-11-17 |
| 뒤로 가기 키(Esc) | 설정 창 열기/닫기만. 시작 화면·보상 창·손상 창에서는 아무 일 없음 | 추천 수락, 2026-11-17 |
| 소리 없이 음량 UI를 넣는가 | 지금 넣고 값만 저장. `Changed` 알림을 두어 나중에 소리 기능이 적용 | 추천 수락, 2026-11-17 |
| 음량 단위와 처음 값 | `int` 0~100, 처음 80 (임시) | 추천 수락, 2026-11-17 |
| 음량 저장 위치 | PlayerPrefs (`save.dat`과 따로) | 추천 수락, 2026-11-17 |
| 제목 글자 | 영문 임시 `PLUM BLOSSOM SWORD`. 한글 글꼴이 준비되면 `매화검 키우기` | 추천 수락, 2026-11-17 |
| 시작 화면 동안 자동 저장 | 저장 있음 + 보상 없음일 때만 켬. 나머지는 시작 흐름에서 켬 | 직접 정함 |
| 시작 화면 동안 전투 | `Battle.SetPaused(true)`, 불투명 화면으로 덮음 | 직접 정함 |
| 설정 창 뒤의 입력 | 가림막이 강화 버튼 입력을 막음. 전투는 계속 | 직접 정함 |
| 음량을 기기에 쓰는 때 | `CLOSE`, 떠나기 직전, 백그라운드·종료. 배치 모드는 쓰지 않음 | 직접 정함 |
| 에디터의 `게임 종료` | 플레이 모드 멈춤 (`#if UNITY_EDITOR`) | 직접 정함 |
| 표시 문구 | 영문 (`START`, `CONTINUE`, `SETTINGS`, `TO TITLE`, `QUIT GAME`, `CLOSE`) | 직접 정함 |
