# 사양 기록 색인

사양 문서(`docs/spec/<기능>.md`)의 이력을 두는 곳이다. 파일 이름은 사양과 같다 (예: `stage.md` → `records/stage.md`). 기획 스킬(`plan-feature`)이 쓰고 읽는다.

- 담는 것: 결정 기록(물은 것과 답), 구현이 끝나 사양에서 옮긴 완료 조건, 구현이 끝나 사양에서 옮긴 변경 기록.
- 구현에 필요한 규칙은 사양 문서에 모두 있다. **구현하는 에이전트와 `make-tasks`는 이 폴더를 읽지 않아도 되고, 작업의 참고 문서에 넣지 않는다.**
- 형식과 옮기는 때는 `.claude/skills/plan-feature/SKILL.md`의 "기록 파일"을 따른다.
- 파일 목록은 따로 적지 않는다. 사양 이름으로 찾는다.
