# 수치 표 기록

[balance.md](../balance.md) 사양의 이력이다. 구현에 필요한 규칙은 사양 문서에 모두 있으므로 **구현하는 에이전트는 읽지 않아도 된다.** 기획 스킬(`plan-feature`)이 이미 정한 것을 다시 묻지 않으려고 읽는다.

## 결정 기록

| 질문 | 답 | 방식 |
| --- | --- | --- |
| 마일스톤 4 사양을 어떻게 나눌까 | 새 문서 3개 (balance, auto_upgrade, regression) | 추천 수락 |
| 작업 순서 | 수치 표 → 자동 강화 → 회귀 → 시뮬레이터 | 추천 수락 |
| 몬스터 능력치·보상의 모양 | 지수 공식. 기본값은 지금 선형 값이 나오게 `내림((기본 + 증가량 × n) × 배율^n)` | 사용자 선택 |
| 강화 비용 공식 | 능력치별 지수 (기본·증가량·배율을 능력치마다) | 추천 수락 |
| 레벨당 상승 | 일정하게 (값만 표로) | 추천 수락 |
| 몬스터 성장 단위 | 구간마다 (`SubstageStep`, 기본 0) | 추천 수락 |
| 천마 수치 | 따로 고정값 (0이면 보스 공식) | 추천 수락 |
| 수치 표 연결 방식 | 공용 값 하나 `BalanceTable.Current` | 추천 수락 |
| 표에 넣을 범위 | 밸런스에 닿는 것 전부 (강화, 시작 능력치, 공격 간격, 스킬, 몬스터, 보상, 천마, 경지) | 추천 수락 |
| 첫 작업에서의 기본값 | 지금 수치와 같게 (기존 테스트 그대로). 새 값은 시뮬레이터로 정해 따로 넣음 | 추천 수락 |
