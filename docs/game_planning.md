# 게임 기획 정리

이 문서는 기획 대화에서 정한 방향과 앞으로 확인할 사항을 모은 진행 중인 문서다. 기능별 확정 사양이나 루프에 투입할 작업 문서는 아니다.

## 프로젝트 범위

- 1주일짜리 프로젝트로, 기능과 콘텐츠를 크게 확장하지 않는다.
- 많은 종류의 무공이나 스킬보다 전투, 보상, 강화, 스테이지 진행이 이어지는 핵심 흐름에 집중한다.
- 필수 범위인 경지 돌파와 저장·오프라인 보상도 작은 형태로 기획한다.

## 마일스톤

마일스톤은 기능 하나를 완성하는 순서가 아니라 여러 기능을 필요한 만큼 묶어 게임 전체의 진행 정도를 확인하는 기준이다. 각 단계의 결과를 직접 확인하고 다음 단계에 반영한다.

1. **핵심 재미 검증**: 일반 몬스터 여러 마리와 마지막 적으로 구성된 간단한 스테이지에서 자동 전투 → 재화 획득 → 강화 → 재도전이 이어지는 프로토타입을 플레이한다. 화면과 수치는 간단한 임시 형태로 시작한다.
2. **방치형 진행 완성**: 보스의 세부 규칙을 정하고 스테이지 진행을 발전시키며 저장·불러오기와 오프라인 보상을 연결한다.
3. **성장과 목표 확장**: 경지 돌파와 성장 보너스를 추가하고 전투·강화 수치를 조정한다.
4. **포트폴리오용 정리**: 필요한 화면과 연출을 개선하고 전체 흐름과 AI 개발 과정·결과를 정리한다.

## 지금까지 정한 게임 흐름

- 자동 전투 중 몬스터를 처치하면 재화를 얻는다.
- 캐릭터와 적이 서로 자동으로 공격한다. 적의 체력이 0이 되면 처치하고 재화를 얻어 다음 적이 등장하며, 캐릭터의 체력이 0이 되면 패배한다.
- 재화가 충분하면 전투 중에도 실시간으로 공격력·체력·공격 속도를 강화할 수 있다.
- 강화 중 스테이지에 실패해도 구매한 강화와 남은 재화는 유지된다.
- 1단계부터 스테이지마다 일반 몬스터 여러 마리를 처치하고 마지막 적에게 도전한다. 적을 처치할수록 조금씩 강한 적이 등장한다. 몬스터 수와 성장 수치는 아직 정하지 않았다.
- 1단계에서 패배하면 체력을 모두 회복하고 같은 스테이지의 첫 일반 몬스터부터 자동으로 다시 싸운다. 몬스터를 다시 처치할 때 재화를 얻으며, 기존 재화와 강화는 유지된다.
- 보스는 일정 수의 일반 몬스터를 처치하면 등장한다. 1단계의 마지막 적은 간단한 형태로 두고, 보스의 세부 규칙과 추가 연출은 이후 정한다.
- 보스 처치에 성공하면 다음 스테이지로 자동 진행한다.
- 스테이지에 실패하면 체력을 모두 회복하고 **실패한 스테이지를 처음부터** 자동으로 다시 시작한다. 재화를 모아 강화하며 재도전할 수 있다.

## 아직 정하지 않은 사항

- 적과 능력치가 성장하는 수치와 계산식.
- 강화 효과가 전투에 반영되는 정확한 시점과 체력 강화 시 현재 체력의 변화.
- 스테이지별 적의 수, 보스 규칙과 스테이지 실패의 구체적인 조건.
- 기능별 연결 지점, 화면 세부 사항, 저장과 오프라인 보상 규칙.

## 기존 공용 문서에 반영할 사항

- `docs/plan.md`의 **2. 게임 설계 → 진행 방식**에는 보스 실패 시 이전 스테이지로 돌아간다고 적혀 있다. 현재 결정은 **체력을 모두 회복하고 실패한 스테이지를 처음부터 자동 재도전**하는 것이므로, 추후 계획서를 정리할 때 해당 문장을 수정해야 한다.
- 같은 위치에 성공 시 다음 스테이지 자동 진행, 실패해도 강화와 남은 재화 유지, 전투 중 실시간 강화를 반영할 수 있다.
- 계획서에는 개발 기간이 2주로 적힌 곳이 있다. 현재 기획 기준은 1주일이므로 추후 관련 내용을 확인하고 수정해야 한다.
