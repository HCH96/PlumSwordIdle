# 공용 문서 색인

작업을 시작하기 전에 이 색인을 먼저 읽고, 작업에 필요한 문서만 골라 읽는다.
새 공용 문서를 만들거나 기존 문서의 역할이 바뀌면 이 색인도 함께 갱신한다.

| 경로 | 설명 |
| --- | --- |
| [docs/plan.md](plan.md) | 프로젝트 계획서. 목적, 게임 설계·구현 범위, 아트·사운드, AI 자동 개발 루프 설계, 스킬 목록 |
| [docs/loop.md](loop.md) | AI 자동 개발 루프 스크립트 사용법. 실행·감시 모드, 설정값, worktree, 브랜치 구조, 선행 작업·wait, 묶음, 중단 복구, 일시적 오류, 클로드 권한(검사 훅, 막혔을 때 확인하는 곳), 코덱스 전환, 결과 파일 형식, 알림 |
| [docs/task_template.md](task_template.md) | 작업 문서 양식. 칸 목록, 선행 작업·묶음 적는 규칙 |
| `docs/history/` | 완료된 작업 문서 원본(보고서 포함) 기록. 루프가 작업 완료 시 자동으로 추가한다 |
