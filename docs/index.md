# 공용 문서 색인

작업을 시작하기 전에 이 색인을 먼저 읽고, 작업에 필요한 문서만 골라 읽는다.
새 공용 문서를 만들거나 기존 문서의 역할이 바뀌면 이 색인도 함께 갱신한다.

| 경로 | 설명 |
| --- | --- |
| [docs/plan.md](plan.md) | 프로젝트 계획서. 목적, 게임 설계·구현 범위, 아트·사운드, AI 자동 개발 루프 설계, 스킬 목록. 게임 설계가 `docs/game_planning.md`와 다르면 그쪽이 최신이다 |
| [docs/architecture.md](architecture.md) | 코드 구조. 폴더와 어셈블리, 네임스페이스, 순수 C# 규칙이 강제되는 방식, 화면을 코드로 조립하는 방식, 테스트 위치와 실행 명령, `.meta` 파일. **코드를 쓰는 작업은 반드시 읽는다** |
| [docs/loop.md](loop.md) | AI 자동 개발 루프 스크립트 사용법. 실행·감시 모드, 설정값, worktree, 브랜치 구조, 선행 작업·wait, 묶음, 중단 복구, 일시적 오류, 클로드 권한(검사 훅, 막혔을 때 확인하는 곳), 코덱스 전환, 결과 파일 형식, 보고서 양식, 실행 중 기록, 알림 |
| [docs/task_template.md](task_template.md) | 작업 문서 양식. 칸 목록, 선행 작업·묶음 적는 규칙 |
| [docs/game_planning.md](game_planning.md) | 기획 진행 기록. 마일스톤, 게임 흐름의 결정과 미결 사항, 기존 문서에 반영할 변경 |
| `docs/spec/` | 기능별 사양 문서 (`plan-feature` 스킬이 쓴다). 동작, 수치, 연결 지점, 화면, 저장, 완료 조건 초안. 연결 지점의 원본은 각 사양 문서의 "연결 지점" 절이다. 사양이 생길 때마다 이 표에 한 줄씩 추가한다 |
| `docs/history/` | 완료된 작업 문서 원본(보고서 포함) 기록. 루프가 작업 완료 시 자동으로 추가한다 |
