# 종남파 스테이지 UI 원본 색인

| 자료 | 파일 | 크기 | 방향·프레임 | 상태 |
| --- | --- | --- | --- | --- |
| 종남파 진행도 틀 | [stage_hud_concept.png](stage_hud_concept.png) | 2172×724px | 정지 이미지, 해당 없음 | 사용자가 선택함, 1스테이지 적용 |
| 매화 아래 비무 제목 | [title_plum_duel_concept.png](title_plum_duel_concept.png) | 2172×724px | 정지 이미지, 해당 없음 | 사용자가 선택함, 일반 전투에 적용 |

- Codex 내장 이미지 생성. 종남 제자 일러스트의 흰색·남색 도복과 게임 화면의 분위기를 참고해 제작했다.
- 생성 지시 요약: 어두운 남색 무협 문파 패, 흰 천과 은색 장식, 교차한 검, 글자와 진행 바를 얹을 빈 공간, 투명 바탕.
- 원본을 그대로 `Assets/Resources/Art/UI/jongnam_stage_hud.png`에 복사했다. 화면에서의 크기와 진행 바는 [에셋 목록](../../../docs/dev/assets.md)을 따른다.
- 제목은 선택한 틀과 시작 화면 제목을 참고해 Codex 내장 이미지 생성으로 만들었다. 생성 지시: `매화 아래 비무` 한 줄, 밝은 상아색 무협 붓글씨와 짙은 남색 외곽, 투명 배경. 게임용 `Assets/Resources/Art/UI/jongnam_title_plum_duel.png`는 원본에서 바깥 투명 여백만 자른 1917×462px이며 그림을 확대·축소하지 않았다.
