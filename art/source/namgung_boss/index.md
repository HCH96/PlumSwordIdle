# 남궁 장로 보스 시안

2026-11-22 사용자가 승인한 [일러스트 시안](concept_approved.png)은 남궁 일반 검객의 청백색 복장을 바탕으로 짙은 푸른 도복과 금빛 장식, 백발·수염·주름과 직검을 가진 노장이다. 내장 이미지 생성으로 제작했다.

PixelLab Pro, 96×96, 8방향, low top-down. 승인 시안의 외형을 글로 설명하고 기존 종남 장로 `0db24a81-6d08-4887-8eaf-504bc24d0817`를 스타일 참고로 사용했다. 캐릭터 ID `a853ef61-6e76-40dd-95ee-85f236eaa43c`; 남서쪽 기본 그림의 불투명 픽셀 높이는 70px로 종남 장로와 같고 화산 제자(53px)보다 크다. [PixelLab 원본 ZIP](pixellab_v2.zip)에 방향별 그림과 애니메이션 프레임을 보관한다. 앞선 첫 캐릭터 `e2d98729-1e56-44a8-966c-6ff9bbfe43a6`는 몸이 작게 생성되어 사용하지 않았다.

남서쪽 PixMiniMax. 미리보기는 어두운 배경에 원본을 합성해 최근접 3배로 확대하고 10fps로 반복한다. 쓰러짐도 검토를 위해 반복한다. 아래는 처음 제작한 시안이다.

| 동작 | 재생 | 칸·프레임 | PixelLab 그룹 |
| --- | --- | --- | --- |
| 대기 | [보기](idle_preview.gif) | 100×100, 17 | `ff777370-bbcf-4d72-8d87-094819f6adc5` |
| 이동 | [보기](walk_preview.gif) | 100×100, 25 | `c3ad3ff2-5bbe-4d3b-9d1e-882cefe05323` |
| 공격 | [보기](attack_preview.gif) | 100×100, 25 | `388cf144-2a6d-49bc-8176-73a7f3f7b9c4` |

생성 지시: 대기는 제자리에서 미세한 호흡과 수염·옷 움직임, 이동은 왼쪽 앞을 향한 제자리 걷기, 공격은 청백색 검기와 함께 한 번 베고 복귀, 쓰러짐은 화면 오른쪽으로 넘어져 누운 채 끝낸다. 게임 속도·피벗과 별도 보스 기술은 아직 정하지 않았다.

## 공격 수정 시안

사용자 요청으로 공격만 다시 생성했다. 왼쪽 앞을 바라보며 검을 들어 오른쪽 위에서 왼쪽 아래로 한 번 베고, 흰 검기가 사라지면서 원래 자세로 돌아오도록 요청했다. PixMiniMax 남서쪽, 100×100, 25프레임, 그룹 `0d96cca7-c21b-4fff-8b85-d6d24623f079`. [10fps 반복 미리보기](attack_v2_preview.gif), [PixelLab 원본 ZIP](pixellab_attack_v2.zip). 사용자 확인 전이다.

## 보스 기술 시안

검에 청백색 기운을 모은 다음 크게 휘둘러 푸른 검기와 불꽃을 펼치고 자세로 돌아오도록 요청했다. PixMiniMax 남서쪽, 100×100, 기준 그림 포함 37프레임, 그룹 `249b2e9f-aa44-402f-a385-65e920102579`. [재생 미리보기](skill_preview.gif)는 원본을 어두운 배경에 합성해 3배 확대하고 12.5fps로 반복한다. [PixelLab 원본 ZIP](pixellab_skill.zip). 사용자 확인 전이며 기술 효과와 게임 적용은 정하지 않았다.

## 발사 스킬 수정 시안

사용자 요청으로 검 끝에 푸른 에너지를 충전한 뒤 왼쪽으로 발사하는 화려한 원거리 기술을 새로 만들었다. 생성 결과 발사 이후 짧은 검 휘두름도 나타난다. PixMiniMax 남서쪽, 100×100, 37프레임, 그룹 `1eec465c-9f96-4b08-8236-3dafc6a7800f`. [12.5fps 미리보기](skill_beam_v2_preview.gif), [PixelLab 원본 ZIP](pixellab_skill_beam_v2.zip). 검토 대기이며 게임에는 적용하지 않았다.

## 연속 타격 이펙트 시안

사용자가 제공한 [참고 영상](https://www.youtube.com/shorts/02WEJO02RIc)의 전방 연속 타격과 수직 빛기둥을 참고해, 장로 앞 왼쪽으로 청백색 빛기둥 세 개와 전기 섬광·교차 검기가 차례로 터지는 별도 이펙트를 만들었다. PixelLab VFX Workbench의 sky_beam·zap_hit·cross_slash를 조합했다. 장로는 크기와 위치를 확인하기 위한 정지 기본 그림이다. 247×144px, 32프레임, 14fps, 발 기준점 (213, 126)px, 1회 재생용. [2배 반복 검토본](skill_sequential_review.gif), [원본 GIF](skill_sequential_preview.gif), [레이어별 게임 팩](skill_sequential_gamepack.zip), PixelLab 효과 ID `ea4ff9ab-8558-428f-98d8-d281a4250888`. 앞뒤 빈 프레임은 발동 전후 여유다. 아직 사용자 확인이나 게임 적용 전이다.

## 검을 내미는 연속 빛기둥 시안

사용자 요청으로 장로가 검을 앞으로 내밀고 유지하는 동작을 새로 생성해 세 빛기둥과 합성했다. 검이 전방을 가리키는 8번째 프레임부터 빛기둥이 앞쪽으로 순차 발생한다. PixMiniMax 장로 동작 그룹 `01e6a253-c271-4ac7-8404-83b58cc5a6d3`, [캐릭터 원본 ZIP](pixellab_thrust.zip). PixelLab VFX 효과 `4cc04a23-84d3-44cb-a627-4d8f58f0b07a`: 252×144px, 25프레임, 11fps, 발 기준점 (212, 126)px. [2배 반복 검토본](skill_thrust_pillars_review.gif), [원본 GIF](skill_thrust_pillars.gif), [레이어별 게임 팩](skill_thrust_pillars_gamepack.zip). 당시 확인 대기였다.

사용자가 위 기술을 승인해 장로의 대기·이동·수정 공격·쓰러짐과 함께 3스테이지에 적용했다. 기술의 게임용 시트는 게임 팩의 `whole-with-sprite.png`를 사용하며 크기와 피벗은 [에셋 목록](../../../docs/dev/assets.md)을 따른다. 다른 보스와 일관되게 매 세 번째 공격에 재생하고 기존 근접 피해를 한 번 주는 것은 임시 가정이다.
