## 제목·배경

- 내용: 화산 산길과 매화, 제자, `매화검 키우기` 제목. 아래 가운데는 버튼을 놓을 공간이다.
- 생성: Codex 내장 이미지 생성. 참고 자료는 [제자 일러스트](../disciple/illustration_concept.png)와 [기본 스프라이트](../disciple/base_south-east.png). PixelLab은 사용하지 않았다.
- 생성 지시 요약: 가로형 무협 시작 화면, 기존 제자의 검은 의상과 붉은 끈, 산과 정자와 매화, 픽셀아트풍 명암, 한글 제목과 두 버튼을 위한 여백. 버튼은 이미지에 그리지 않는다.
- 단일 정지 이미지이며 방향·프레임 수·재생 속도는 해당 없다.
- 게임 적용: 확대·축소 없이 그대로 복사했다. 비율이 16:9라 640×360 화면에 꼭 맞고, 더 긴 가로 화면에서는 위아래가 조금 잘린다 (제목과 제자는 남는다).

## 버튼 시안

- `게임 시작`과 `설정`이 세로로 배치된 한 장의 시안이다. 배경은 불투명한 단색(RGB 약 60, 40, 60)이고 글자는 그림에 포함되어 있다.
- 생성: Codex 내장 이미지 생성. 선택된 시작 화면 일러스트를 색감과 표현의 참고로 사용했다. PixelLab은 사용하지 않았다.
- 생성 지시 요약: 짙은 자주색 바탕, 어두운 청동색·붉은 테두리, 매화 장식과 밝은 한글 붓글씨의 무협풍 버튼 두 개.
- 정지 이미지이며 방향·프레임 수·재생 속도는 해당 없다.

### 게임용으로 나눈 방법 (`prepare_buttons.py`)

1. 위쪽 판(원본 위치 x 171~1604, y 157~418)과 아래쪽 판(x 171~1606, y 500~760)을 잘라낸다. 확대·축소하지 않는다.
2. 판 바깥에서 이어진 단색 바탕을 투명하게 한다. 바탕보다 어두운 판 아래 그림자는 반투명 검정으로 남긴다. 판의 검은 바깥선은 그대로다. 초록 바탕에 얹어 네 모서리와 그림자에 자주색 테두리가 남지 않았는지 확인했다.
3. `설정` 판의 글자 자리(원본 x 692~1077, y 529~726)를 좌우의 빈 바탕 색으로 이어 칠해 빈 판을 만든다.
4. 빈 판에 `이어하기`를 Noto Serif KR Black(SIL OFL 1.1, Windows에 설치된 `NotoSerifKR-VF.ttf`, 환경 변수 `CONTINUE_FONT`로 바꿀 수 있다)으로 그린다. 글자색은 시안 글자(RGB 약 252, 211, 209), 오른쪽 아래로 어두운 그림자, 붓글씨처럼 살짝 기울임. **붓글씨가 아니라 임시다.** 같은 붓글씨로 다시 만들려면 이미지 생성으로 `이어하기` 글자나 버튼을 만든 뒤 이 파일을 바꾼다.
5. 세 장 모두 1436×262 투명 캔버스 가운데에 놓아 크기를 맞춘다.

실행 (프로젝트 폴더에서, Pillow·numpy 필요): `python art/source/start_menu/prepare_buttons.py`

## 시작 화면 꽃잎 파티클

- 사용자가 선택한 세 장의 정지 원본이다. 각각 투명 알파 채널이 있고, 펼쳐진 꽃잎과 접힌 꽃잎에는 부드러운 분홍빛이 포함되어 있다. 방향은 각각 대각선, 가로, 대각선이다.
- 생성: Codex 내장 이미지 생성. 선택한 시작 화면을 색감과 그림체 참고로 사용했다. PixelLab은 사용하지 않았다.
- 생성 지시 요약: 분홍색 꽃잎 한 장씩, 픽셀 계단형 외곽과 단순한 명암, 투명 배경. 펼쳐진 모양, 옆으로 휘어진 모양, 접힌 모양을 각각 요청했다.
- 애니메이션 프레임과 재생 속도는 해당 없다 (움직임은 코드가 회전·뒤집기·이동으로 만든다).
- 게임 적용 (`prepare_petals.py`): 알파 > 8인 꽃잎 테두리로 잘라 긴 변 64px(투명 여백 2px 포함)로 BOX 축소했다. 원본 꽃잎의 픽셀 한 칸이 약 8px이라 줄인 뒤 거의 1:1이고, 알파를 곱한 색으로 줄여 가장자리에 검은 테두리가 생기지 않는다. 화면에서는 긴 변 7~14 UI 단위로 보인다. 움직임은 [시작 화면 사양](../../../docs/spec/start_menu.md) "매화 꽃잎 흩날림".

실행 (프로젝트 폴더에서, Pillow·numpy 필요): `python art/source/start_menu/prepare_petals.py`
