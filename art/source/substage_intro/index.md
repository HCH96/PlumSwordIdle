# 작은 스테이지 번호 연출

- `plaque_source.png`: 내장 imagegen으로 생성한 투명 배경 번호 패 원본. 게임에는 `Assets/Resources/Art/UI/Substage/intro_plaque.png`로 복사했다.
- 참고: 기존 [작은 스테이지 상단 UI](../substage_ui/index.md)의 금색·검붉은색과 매화 장식. PixelLab은 사용하지 않았다.
- 생성 문구: 기존 UI의 색과 표현을 참고해 숫자를 넣을 가운데가 비어 있는 무협풍 가로 패를 만든다. 짙은 자주색 바탕, 금색 가장자리, 양쪽 매화와 검 장식, 투명 배경. 글자·숫자는 그리지 않는다.
- 화면에서는 번호를 별도 텍스트로 올리고 코드로 위치·크기·투명도를 애니메이션한다. 사용자가 확인해 최종 에셋으로 확정했다.
