# 5스테이지 천마 배경

- `concept.png`: 사용자가 B로 선택하고 5스테이지 적용을 요청한 내장 imagegen 원본 (2172×724). 같은 파일을 `Assets/Resources/Art/Backgrounds/stage5_tianmo.png`에 보관한다.
- 생성 문구: 오래된 검은 기둥이 늘어선 천마신교의 어두운 대전, 그늘진 제단, 찢어진 암적색 장막과 붉은 등불, 절제된 핏자국. 하단에는 넓은 회색 돌바닥을 두고 낮은 3/4 픽셀아트 시점, 양끝의 좌우 반전 반복을 고려한다. 인물·글자·UI는 제외한다. 기존 3스테이지 배경을 화풍과 구도 참고로 사용했다.
- 1~3스테이지와 동일하게 높이 18유닛, 중심 y=2.9, 좌우 반전 반복을 사용하며 시차 레이어는 없다. Point·무압축·밉맵 끔, 최대 텍스처 크기 2048로 가져온다.
