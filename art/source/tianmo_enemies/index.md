# 천마신교 일반 상대 애니메이션 시안

- `concept.png`: 사용자가 선택한 마검사·흑갑 호위 디자인 시안. 내장 imagegen 생성.
- PixelLab Pro 기본 그림: 마검사 `5a7ab46e-82e4-42e4-95ea-1d93eea7cf3e`, 호위 `a809a558-80f9-414e-9c21-fd6d1a676513`. 각 64×64, 8방향, low top-down. 제자 `6c24a0f7-bff6-4d33-88cc-a7839592c1dd` 스타일 참고. 남서 방향 기본 그림을 사용자가 승인했다.
- 각 동작 폴더의 `frame_000.png`부터는 PixMiniMax 원본 프레임이며 64×64, 투명 배경이다. `*_preview.gif`는 어두운 바탕에 4배 최근접 확대하고 10fps로 반복한 검토용이다. `*_all_preview.gif`는 네 동작을 나란히 보여 주며 쓰러짐은 마지막 프레임을 유지한다.
- 생성 지시: 대기는 발을 고정하고 호흡, 이동은 왼쪽 앞을 향해 제자리 걷기, 공격은 왼쪽 앞을 향해 무기를 한 번 휘두르고 복귀, 쓰러짐은 오른쪽 뒤로 넘어져 멈춤. 검토용 재생 속도이며 게임 적용 속도는 미정이다.

- 호위 최초 공격 `f2cbb439-ae89-4b52-97e4-4c7ec383c0a7`은 동작이 약해 `guard_attack/`에 보존하고, 무기를 들어 왼쪽으로 크게 베도록 다시 만든 `guard_attack_v2/`를 미리보기에 사용한다.
- 마검사 수정 공격 `2cf35e76-3b77-4b10-911a-21437b325bb7`: 기존 아래쪽 공격 대신 검을 허리 높이에서 화면 왼쪽으로 수평으로 찌르고 원래 자세로 돌아온다. 사용자가 승인했다. 25프레임 원본은 `swordsman_attack_v2/`, 검토용은 `swordsman_attack_v2_preview.gif`다. 기존 공격 원본도 보존한다.
- 대기·쓰러짐은 17프레임, 이동·공격은 25프레임이다. 사용자가 수정한 마검사 공격을 승인하여 `swordsman_attack_v2`와 `guard_attack_v2`를 포함한 시트를 만들었다. 두 상대의 소속은 천마신교 4스테이지다. 현재 게임의 5스테이지 배치는 잘못된 상태이며 4스테이지로 수정할 예정이다. 실제 어두운 배경에서의 가독성과 동작 연결은 플레이 화면에서 확인한다.
