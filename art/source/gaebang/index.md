# 개방 일반 상대 에셋

2스테이지의 일반 상대 두 종. 2026-11-21 사용자가 일러스트, 기본 스프라이트와 수정 애니메이션을 승인해 게임에 적용했다.

| 대상 | 승인된 일러스트 | PixelLab 캐릭터 ID |
| --- | --- | --- |
| 막대 상대 | [concept_staff.png](concept_staff.png) (머리는 민머리로 수정) | `ec44cf27-7739-4bc7-8e7b-2e2365aefc68` |
| 맨손 상대 | [concept_unarmed.png](concept_unarmed.png) | `034a8c00-c149-4f6d-ad6f-922cd4e8754e` |

일러스트는 사용자가 제공한 회색 도복과 막대기 참고 이미지, 화산 제자와 종남 상대 일러스트를 참고하여 Codex 내장 이미지 생성으로 만들었다. 막대 상대는 마른 체형과 대나무 막대기, 맨손 상대는 둥근 체형과 빈손을 지정했다.

기본 스프라이트는 PixelLab Pro, 64×64, 8방향, low top-down으로 요청했다. 승인된 각 일러스트를 외형 참고로, 화산 제자 캐릭터 `6c24a0f7-bff6-4d33-88cc-a7839592c1dd`를 스타일 참고로 사용했다. 전투에서는 남서쪽 방향을 비교한다.

검토용 화면: [막대 상대](base_staff_preview.png), [맨손 상대](base_unarmed_preview.png), [기존 캐릭터와 크기 비교](comparison_preview.png). 이는 PixelLab 화면 미리보기이며 원본 스프라이트 파일이 아니다. 기본 스프라이트 확정 후 원본과 애니메이션을 보관한다.

사용자가 첫 막대 상대의 머리가 주인공과 너무 비슷하다고 지적하여 완전히 깎은 민머리로 다시 생성했다. [수정 비교 미리보기](comparison_bald_preview.png)는 왼쪽부터 화산 제자, 종남 상대, 수정한 막대 상대, 맨손 상대다. 이전 막대 상대 ID는 `0f3a7be0-18eb-4102-a1d9-750818f9a5cf`이며 위 첫 미리보기는 이전 버전이다.

2026-11-21 수정본과 맨손 상대를 확인받고 남서쪽 애니메이션을 요청했다. 첫 대기는 V3 8프레임, 걷기·공격은 PixMiniMax 24프레임, 쓰러짐은 PixMiniMax 16프레임이다. 제자리 호흡과 걷기, 각각 막대 한 번 휘두르기와 맨손 한 번 지르기, 넘어져 누운 채 끝나는 동작을 요청했다. 아래 2차 시안에서 일부 동작을 교체했다.

## 사용자 요청에 따른 2차 동작 시안

첫 대기 둘은 자세 변화가 크고 막대 걷기는 끊긴다는 의견으로 다시 제작했다. 두 대기는 제자리에서 자세·발·시선을 유지하며 미세하게 호흡하고 시작 자세로 돌아가도록 요청했다. 막대 걷기는 발을 번갈아 일정하게 내딛고 시작 자세로 돌아가는 반복을 요청했다. 맨손 쓰러짐은 화면 왼쪽으로 넘어져 머리가 왼쪽에 놓이도록 바꿨다. 모두 남서쪽, PixMiniMax이며 사용자가 승인했다.

수정 동작을 포함한 원본은 [막대 ZIP](staff_pixellab_v2_export.zip)과 [맨손 ZIP](unarmed_pixellab_v2_export.zip)에 별도로 보관한다. 기존에 생성한 공격 등 다른 동작은 변경하지 않았다. 미리보기는 10fps이며 쓰러짐도 확인 편의를 위해 반복한다.

승인한 2차 대기·막대 이동·맨손 쓰러짐과 1차의 나머지 동작을 사용한다. 게임용 프레임 시트와 기준점은 [에셋 목록](../../../docs/dev/assets.md)에 기록했다.
